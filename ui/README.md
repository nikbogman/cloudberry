# UI

The browser app, hosted on Cloudflare Pages: shows whether blackberry is
[Reachable](../CONTEXT.md) and offers Wake/Suspend. The only user-facing surface
in the system.

Plain static files — HTML, one ES module, one stylesheet. No framework, no
bundler, no build step.

Code: [`ui/`](.).

## Behavior

All of it lives in [`mountUi`](app.js), called by the inline module script
in [`index.html`](index.html):

- Polls hostd's `/health` every 12s (configurable), renders
  `Checking…` / `Reachable` / `Unreachable`.
- **Wake button** — enabled unless already reachable. `POST`s to
  gateway's `/wake`.
- **Suspend button** — enabled unless already unreachable. `POST`s to
  hostd's `/suspend`.
- Failures surface in an error line; successes don't.

The browser calls [gateway](../cmd/gateway/README.md) and
[hostd](../cmd/hostd/README.md) directly at their tailnet URLs, so it only works
from a device on the tailnet. Both backends allow the page's origin
(`UI_ORIGIN`) via CORS; `tailscale serve` adds the identity header.

## Configuration

`config.js`, generated by `task ui` from the repo root `.env`, not committed:

```js
export default { gatewayBaseUrl: "$GATEWAY_URL", hostdBaseUrl: "$HOSTD_URL" }
```

## Deployment

`task ui` copies the files to `dist/ui/`, writes `config.js`, and uploads it
with `npx wrangler pages deploy` to the production branch of the Pages project
`$CLOUDFLARE_PAGES_PROJECT` (default `cloudberry`). Needs Node on the dev
machine; the first run asks you to log in to Cloudflare and, if the project
doesn't exist, to create it.

Then set `UI_ORIGIN` to the production origin (e.g.
`https://cloudberry.pages.dev`) and redeploy gateway and hostd so CORS allows
it. Preview deployments have other origins and can't call the backends.

## Development

There is no local loop against the real backends: CORS only allows
`UI_ORIGIN`. Edit, `task ui`, reload. Asset paths are relative; `file://`
URLs don't work, since ES modules need an HTTP origin.
