# WoL requires same L2 broadcast domain, no cross-subnet relay

Wake-on-LAN magic packets are broadcast on the local L2 segment and don't route across subnets or VLANs without a directed-broadcast route or a WoL relay. This system requires the Pi Zero and the main server to remain on the same broadcast domain and does not implement any cross-subnet WoL mechanism. We chose not to build a relay/directed-broadcast path since both devices are on the same LAN today and the added complexity isn't justified. If either device is ever moved to a different VLAN or subnet (e.g. an IoT or guest network), both the Pi API's wake action and the Caddy Pi proxy will silently stop working — there is no error path for this, since a magic packet that never arrives looks the same as no request at all.
