# Git-pull deploy model, with the UI built off-device

Each Concern's pyinfra deploy has the target device `git clone`/pull this repo directly and check out a specific ref, so deployed state is always traceable to a commit rather than to whatever happened to be in the dev machine's working copy at Deploy time. The UI is a deliberate exception: it's built on the dev machine (Vite build) and only the static `dist/` output is delivered to the Pi Zero. We rejected building it on-device because the Pi Zero is a single-core, low-memory device — the framework-light SPA was chosen specifically so the Pi never needs to run a Node toolchain, and building on-device would undermine that.
